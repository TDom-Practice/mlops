# Stakeholder Summary

Команда готує контейнеризовану версію pretrained-моделі класифікації зображень, 
щоб її можна було відтворювано запускати в різних середовищах.  
Docker image пакує застосунок і потрібні runtime-залежності в артефакт, 
який можна перевіряти та передавати через delivery pipeline.  
Передбачено два варіанти: базовий fat image на `python:3.13` і
оптимізований slim image на `python:3.13-slim`.  
Slim-варіант має використовувати multi-stage build і містити лише компоненти, 
необхідні для роботи моделі. При цьому обидва образи повинні повертати узгоджені
top-3 predictions для однакового тестового зображення.  
Успішний локальний запуск є лише першим кроком, оскільки staging також потребує
перевірки залежностей, конфігурації, безпеки та відтворюваності.  
До приймання команда має надати вимірювання розміру образів, часу збірки й
запуску, аналізу вмісту та security findings.  
Основні ризики включають несумісність бібліотек із Python 3.13, зміну результатів inference 
після оптимізації, відсутність версії моделі та випадкове підключення локального стенду до production-ресурсів.  
Усі невідомі метрики мають бути підтверджені логами й результатами перевірок, а не оцінені приблизно.  
Успішним результатом буде відтворювана збірка обох образів, еквівалентний inference, документовані метрики та 
закриті або формально погоджені ризики перед переходом до staging.
